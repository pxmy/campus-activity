# 业务规则说明

## R1 报名检查（依次）
1. 活动状态为“报名中”，且当前时间不晚于报名截止时间；
2. 同一学生对同一活动不存在有效报名（取消后允许再次报名）；
3. 有效报名数未达到活动名额。
检查与写入在同一事务（BEGIN IMMEDIATE）内完成，数据库唯一索引兜底重复报名。

## R2 场地时间冲突
同一场地存在未取消的活动，且两时间段满足“甲开始 < 乙结束 且 乙开始 < 甲结束”即冲突；
首尾相接不算冲突；修改活动时排除自身。

## R3 实践成绩计算
出勤分：准时40、迟到30、缺席记0；任务分：完成度×0.5；反馈分：结束后3天内提交得10。
缺席直接记0。三项相加后用 Decimal ROUND_HALF_UP 取整。
尚未登记到场，或已到场但任务未评定，成绩为空（显示“未评定”），不得显示0。
等级：≥90优秀，80-89良好，60-79合格，<60不合格。

## 状态转换
draft→open/cancelled；open→closed/cancelled；closed→finished/cancelled；finished与cancelled为终态。
