# 统计口径说明

| 指标 | 分子 | 分母 | 特殊情况 |
|---|---|---|---|
| 报名率 | 有效报名人数 | 活动名额 | 取消报名不计入分子；上限100% |
| 到场率 | 到场人数（准时+迟到） | 有效报名人数 | 未登记到场的活动显示“—” |
| 完成率 | 任务分≥60人数 | 到场人数 | 到场未评定者计入分母不计入分子，页面注明未评定人数 |
| 平均实践成绩 | 有成绩者成绩之和 | 有成绩人数 | 成绩为空者不参与；缺席0分参与 |

通用约定：
1. 分母为0时显示“—”，不显示0或报错；
2. 汇总比率用“分子之和÷分母之和”，不对各活动比率取平均；
3. 按活动开始时间落入筛选区间统计，已取消和草稿活动不计入；
4. 按学院筛选时分子分母都只统计该学院学生；
5. 导出CSV用带BOM的UTF-8，Excel打开中文正常，数值与页面一致。
