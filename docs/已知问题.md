# 已知问题清单

1. 智能功能（反馈分类、问答、签到表识别、语音转写、工具助手）依赖真实 DeepSeek 接口，
   需在配置有效密钥后联调；无密钥时已实现降级与友好提示，业务功能不受影响。
2. 语音识别接口在指导书编写时未连接验证，切分函数已测试，转写函数需在本机验证格式与返回结构。
3. 提示词注入防护已在分类与问答中实现，但模型仍可能输出格式偏差，校验失败会记为失败而非写入脏数据。
4. 评测脚本需调用模型并产生费用，不纳入 pytest 自动运行。
5. 看板明细表“平均实践成绩”列可能同时含数值与“—”（未评定），Streamlit 底层转 Arrow 时会打印一条类型自动修复警告；
   表格显示与导出均正常，不影响口径与数值，后续可统一为字符串类型消除该警告。
