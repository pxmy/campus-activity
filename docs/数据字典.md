# 数据字典

> 依据指导书附录 D.1，保留各表主键与外键关系。相比参考设计增加了 4 张表用于单元 6—8 的产出（feedback_topics、corrections、workflow_runs 已在 schema.sql 中），均为新增表，不改变原有主外键。

## users 用户表
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| user_id | INTEGER | PK, AUTOINC | 用户编号 |
| username | TEXT | NOT NULL, UNIQUE | 用户名 |
| role | TEXT | CHECK ∈ {student,organizer,admin} | 角色 |
| student_id | TEXT | FK→students | 学生用户绑定的学号 |

## students 学生表
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| student_id | TEXT | PK | 学号 |
| name | TEXT | NOT NULL | 姓名（虚构） |
| college | TEXT | NOT NULL | 学院 |
| class_name | TEXT | NOT NULL | 班级 |
| grade | INTEGER | NOT NULL | 入学年份 |

## venues 场地表
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| venue_id | INTEGER | PK, AUTOINC | 场地编号 |
| name | TEXT | NOT NULL, UNIQUE | 场地名称 |
| capacity | INTEGER | NOT NULL, >0 | 场地容量 |

## activities 活动表
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| activity_id | INTEGER | PK, AUTOINC | 活动编号 |
| title | TEXT | NOT NULL | 活动标题 |
| category | TEXT | NOT NULL | 类别：讲座/竞赛/志愿服务/文体/实践 |
| organizer_id | INTEGER | FK→users | 发布者 |
| venue_id | INTEGER | FK→venues | 场地 |
| start_time | TEXT | NOT NULL | 开始时间 ISO 8601 |
| end_time | TEXT | NOT NULL | 结束时间，须晚于开始 |
| signup_deadline | TEXT | NOT NULL | 报名截止，不晚于开始 |
| capacity | INTEGER | NOT NULL, >0, ≤场地容量 | 活动名额 |
| status | TEXT | CHECK ∈ {draft,open,closed,finished,cancelled} | 状态，默认 draft |
| description | TEXT | 默认 '' | 描述 |

## registrations 报名表（全平台中心）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| reg_id | INTEGER | PK, AUTOINC | 报名编号 |
| activity_id | INTEGER | FK→activities | 活动 |
| student_id | TEXT | FK→students | 学生 |
| status | TEXT | ∈{registered,cancelled}，默认 registered | 报名状态 |
| created_at | TEXT | NOT NULL | 报名时间 |
| attendance | TEXT | ∈{present,late,absent}，可空 | 到场情况 |
| task_score | INTEGER | 0—100，可空 | 任务完成度 |
| feedback_at | TEXT | 可空 | 反馈提交时间 |
| practice_score | INTEGER | 可空 | 实践成绩 |

唯一索引 `uq_active_reg(activity_id, student_id) WHERE status='registered'`：同一学生对同一活动只允许一条有效报名。

## feedback 反馈表
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| feedback_id | INTEGER | PK, AUTOINC | 反馈编号 |
| activity_id | INTEGER | FK→activities | 活动 |
| student_id | TEXT | FK→students | 学生 |
| rating | INTEGER | 1—5 | 评分 |
| content | TEXT | NOT NULL | 反馈文本（不可信输入） |
| created_at | TEXT | NOT NULL | 提交时间 |

## feedback_topics 反馈主题表（U6 新增）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| topic_id | INTEGER | PK | 编号 |
| feedback_id | INTEGER | FK→feedback | 反馈 |
| topic | TEXT | NOT NULL | 主题（须在主题体系内） |
| sentiment | TEXT | ∈{正面,中性,负面} | 情感 |
| — | — | UNIQUE(feedback_id,topic) | 一条反馈同主题只存一条 |

## tool_logs 工具调用日志表（U8）
| 字段 | 类型 | 说明 |
|---|---|---|
| log_id | INTEGER PK | 编号 |
| ts | TEXT | 时间 |
| username / role | TEXT | 调用者 |
| tool | TEXT | 工具名 |
| args_json | TEXT | 参数（截断 500 字） |
| ok | INTEGER | 1 成功 / 0 拒绝或出错 |
| message | TEXT | 说明 |
| duration_ms | INTEGER | 耗时毫秒 |

## corrections 修正记录表（U7 新增）
记录签到表识别的人工修正：activity_id、row_no、field、raw_value、corrected、corrected_by、ts。

## workflow_runs 工作流运行表（U8 新增）
记录周报工作流：week、ts、steps_json（各步状态）、all_ok、output_path。

## 相比参考设计的差异及理由
- 新增 feedback_topics / corrections / workflow_runs 三表：分别承载反馈分类结果、签到表人工修正记录、工作流运行记录，均为指导书单元 6/7/8 要求持久化的数据，不改动原有 7 张表的主外键。
- `services/db.py` 提供 get_conn() 与 get_conn_manual()：后者用于需要显式事务的报名规则（isolation_level=None）。
