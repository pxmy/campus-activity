# 模型说明

## 到场预测
- 基线：同类别历史活动平均到场率 × 报名人数。
- 回归：LinearRegression，特征为报名人数、星期、是否晚间、类别（独热编码）。
- 切分：按开始时间升序取前80%训练、后20%检验，不随机打乱（预测面向未来）。
- 对比：两者在同一检验集上算 MAE。本地120场模拟数据结果为基线8.29、回归9.67，
  基线胜出；数据量小、规律简单时回归不一定更好，如实报告。
- 系数解释：报名人数系数约0.83，表示报名每多1人预计到场多约0.8人；符合常识。

## 可信范围与局限
- 训练数据中未出现过的活动类别：回退到整体平均到场率，误差可能偏大。
- 报名人数远超历史范围的大型活动：线性回归外推不可信。
- 考试周、节假日等特殊时间：历史规律可能失效。
- 训练数据仅几十场时：切分后检验集过小，MAE波动大，不足以判定方法优劣。
- 呈现方式：预测值标注“估计”，同时显示MAE，不作为确定数字。

## 分群
- 特征：报名次数、到场率、平均成绩、参加类别数；参与<2次者单列“参与较少”。
- 聚类前用 StandardScaler 标准化，固定随机种子42，比较3/4/5簇的轮廓系数。
- 簇数由“能否给每个簇起合理名字”决定，不只看指标。
- 页面只展示群体人数与特征均值，不展示学生个人的分群结果，不用于评价个人。
