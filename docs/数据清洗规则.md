# 数据清洗规则（8 类问题）

| 问题类型 | 示例 | 处理方式 |
|---|---|---|
| 格式不规范 | 学号前后空格、全角数字、日期 2026/9/5 | 自动修复入库，清单记“已修复” |
| 关键字段缺失 | 学号或活动编号为空 | 不入库，列异常清单 |
| 非关键字段缺失 | 任务完成度为空 | 入库，成绩按“未评定”，不填0或平均值 |
| 完全重复 | 同一学生同一活动两行内容相同 | 保留一行，其余列清单 |
| 重复且矛盾 | 两行成绩不同 | 都不入库，标“待人工确认” |
| 非法值 | 任务分105、“优”；到场“来了” | 不入库，不截断不猜测 |
| 引用不存在 | 学号/活动编号不在基础表 | 不入库，列清单 |
| 编码问题 | CSV为GBK按UTF-8读乱码 | 识别编码；无法识别报错，不带乱码入库 |

不变量：读取行数 = 入库行数 + 未入库异常行数。任何一行要么入库，要么在清单中有“未入库”记录。
